# Idem 사용자 매뉴얼 (최종 이용자용, 초안)

> 대상: Idem 으로 로그인하는 **서비스 이용자**(기관 포털·업무 시스템의 최종 사용자). 관리자는 `administrator-manual.md`, 기관 개발자는 `../sso-agency-developer-guide.md`. 이 문서는 이용자가 실제로 보는 화면과 그때 할 일만 적는다 — 화면 문구는 1.1.1 코어 설치본 기준이며, 기관이 자기 화면(로그인 버튼·가입 화면)을 따로 꾸밀 수 있다.

## 1. Idem 이 하는 일 (이용자 관점)

- 여러 기관 서비스에 **한 번의 본인확인으로 로그인**한다. 서비스마다 아이디·비밀번호를 만들지 않는다.
- 로그인은 항상 **서비스 화면의 "Idem 으로 로그인" 버튼**에서 시작하고, 끝나면 **그 서비스로 돌아온다**. Idem 자체에는 이용자가 들어가 볼 화면(마이페이지 등)이 없다.
- 한 서비스에서 로그아웃하면 같은 Idem 세션으로 들어간 다른 서비스도 함께 로그아웃될 수 있다(단일 로그아웃, §4).

## 2. 로그인

서비스가 Idem 과 어떤 방식으로 연동됐는지에 따라 두 가지 화면 흐름이 있다. 이용자는 고를 필요가 없다 — 서비스 버튼이 알아서 맞는 쪽으로 보낸다.

### 2.1 표준 로그인 화면 (대부분의 서비스)

1. 서비스에서 **"Idem 으로 로그인"** 을 누른다.
2. Idem 로그인 화면(주소가 Idem 의 SSO 도메인으로 바뀐다)에서 **인증 방법**을 고른다. 설치본·기관 설정에 따라 본인확인(휴대폰 등)·기관이 지정한 인증 제공자가 보인다.
3. 인증을 마치면 서비스로 **자동으로 돌아온다**. 처음 쓰는 서비스면 서비스가 기존 회원 계정과 연결하거나(§3) 가입 화면을 보여 줄 수 있다.
4. 서비스가 **더 높은 인증 수준**(예: 민감 업무 L2·L3)을 요구하면, 이미 로그인돼 있어도 다시 인증을 요구한다. 화면 안내대로 인증하면 된다.

### 2.2 Idem 로그인 선택 화면 (직접 연동 서비스)

1. 서비스에서 **"Idem 으로 로그인"** 을 누른다.
2. **"Idem 로그인 — ○○서비스 에 로그인합니다. 인증 방법을 고르세요."** 화면이 뜨면 목록에서 인증 방법을 누른다. 인증 방법이 하나뿐이면 이 화면 없이 바로 인증 화면으로 간다.
3. 인증 제공자 화면에서 본인확인을 한다.
4. (서비스가 동의 항목을 두었을 때) **"서비스 이용 동의"** 화면이 뜬다(§2.3).
5. 서비스로 **자동으로 돌아온다**. 이미 Idem 에 로그인돼 있으면 2~4 없이 바로 돌아온다.

### 2.3 서비스 이용 동의 화면

- 이용약관·개인정보 처리방침처럼 서비스가 **필수**로 둔 항목에 아직 동의하지 않았을 때만 보인다. "전문 보기" 로 내용을 확인한다.
- **동의하고 계속**: 체크한 항목이 기록되고 로그인이 이어진다. 필수 항목을 빼고 누르면 같은 화면이 다시 뜬다.
- **동의하지 않음**: 로그인이 완료되지 않고 서비스로 돌아간다. 서비스 화면에 "필수 동의를 거부했습니다"(오류 코드 `E-IDO-125`)가 보일 수 있다 — 다시 로그인하면 다시 묻는다.
- 서비스가 동의 항목을 새 버전으로 바꾸면 다음 로그인에서 다시 묻는다. 한 번 한 동의는 서비스가 보관하며 Idem 에는 "언제 어떤 버전에 동의했는지"만 남는다.

## 3. 처음 로그인 — 기존 계정 연결

- Idem 로그인은 **서비스의 기존 회원 계정을 없애지 않는다**. 처음 Idem 으로 들어오면 서비스가 같은 사람의 기존 계정을 찾아 연결하거나(서비스가 정한 기준 — 본인확인 결과·사번·이메일 등), 찾지 못하면 **가입·연결 화면**을 보여 준다. 이 화면은 Idem 이 아니라 서비스의 화면이다.
- 연결이 끝나면 다음부터는 Idem 로그인만으로 그 계정에 들어간다. 연결을 풀거나 바꾸는 것은 서비스 담당자에게 요청한다(Idem 화면에는 없다).
- 서비스가 **이용 대상을 제한**(관리자가 할당한 사용자만)하면, 본인확인은 됐어도 "이 서비스에 할당되지 않은 사용자입니다"(`E-IDO-120`)로 돌아온다. 서비스 담당자에게 이용 신청을 한다.

## 4. 로그아웃과 세션

- **로그아웃은 서비스 화면에서** 한다. 서비스가 Idem 에 로그아웃을 알리면 Idem 세션이 끝나고, 같은 세션으로 들어간 다른 서비스도 로그아웃 통보를 받는다(단일 로그아웃). 통보를 받지 않는 방식으로 연동한 서비스는 그 서비스 안에서 따로 로그아웃해야 한다.
- 세션은 **아무 조작 없이 30분**이 지나면 끝난다. 절대 상한은 직접 연동 서비스(§2.2)가 **로그인 뒤 8시간**, 표준 로그인 화면(§2.1)이 **10시간**이다(운영기관이 바꿀 수 있다). 끝난 뒤 서비스를 쓰면 다시 로그인 화면이 뜬다.
- 공용 PC 에서는 쓰고 나서 **브라우저를 닫는다**. Idem 의 로그인 상태는 브라우저 쿠키에만 있고 닫으면 사라진다.

## 5. 오류 화면과 대처

Idem 화면에서 막히면 **"로그인을 진행할 수 없습니다"** 와 한 줄 설명, 아래에 **오류 코드**와 **추적 ID** 가 보인다. 서비스 담당자에게 문의할 때 **오류 코드와 추적 ID** 를 그대로 전달하면 운영기관이 감사 기록에서 바로 찾을 수 있다.

| 화면 문구(요지) | 오류 코드 | 뜻 | 이용자가 할 일 |
|---|---|---|---|
| 등록되지 않았거나 비활성인 서비스입니다 | `E-AGENCY-307` | 서비스가 Idem 에 등록돼 있지 않거나 운영기관이 중지했다 | 서비스 담당자에게 문의 |
| 이 서비스는 표준 OIDC 로 로그인합니다 | `E-IDO-121` | 서비스 버튼이 잘못된 주소로 보냈다 | 서비스 화면에서 다시 "Idem 으로 로그인" |
| 허용되지 않은 콜백 주소입니다 | `E-AGENCY-304` | 돌아갈 주소가 서비스 등록 정보와 다르다(위조 방지) | 서비스 담당자에게 문의 — 링크를 직접 수정한 경우 원래 버튼으로 |
| 로그인 요청이 만료됐거나 이미 처리됐습니다 | `E-IDO-400` | 화면을 오래 두었거나 뒤로 가기로 되돌아왔다 | 처음부터 다시 로그인 |
| 등록되지 않은 인증 제공자 / 사용할 수 있는 인증 방법이 없습니다 | `E-IDO-109` | 설치본에 인증 방법이 설정돼 있지 않다 | 운영기관 문의 |
| 본인인증에 실패했습니다 | `E-IDO-110` | 인증 제공자에서 실패·취소했다 | 다시 시도. 반복되면 인증 제공자(통신사 등) 문의 |
| 인증 수준이 부족합니다 | `E-IDO-105` | 서비스가 요구하는 수준의 인증이 아니다 | 안내된 방법으로 다시 인증 |
| 이 서비스에 할당되지 않은 사용자입니다 | `E-IDO-120` | 서비스 이용 대상이 아니다 | 서비스 담당자에게 이용 신청 |
| 사용자가 필수 동의를 거부했습니다 | `E-IDO-125` | 동의 화면에서 "동의하지 않음" 을 눌렀다 | 이용하려면 다시 로그인해 동의 |
| 기관 점검 시간입니다 | `E-AGENCY-305` | 서비스가 정한 점검 시간이다 | 점검 뒤 다시 |
| 요청 한도를 초과했습니다 | `E-AGENCY-306` | 짧은 시간에 요청이 몰렸다 | 잠시 뒤 다시(화면의 대기 시간) |
| 안전 우선 거부(장애) | `E-IDO-116` · `E-IDO-117` · `E-IDO-119` | Idem 내부 구성요소 장애 — 로그인을 **내주지 않는다** | 잠시 뒤 다시. 계속되면 운영기관 문의 |
| 표준 로그인 화면에서 `access_denied` 와 함께 서비스로 돌아옴 | (서비스 화면에 코드) | 서비스 정책(할당·수준·점검)에서 거부됐다 | 서비스 화면의 안내에 따른다 |

`E-IDO-1xx`·`E-AGENCY-3xx` 는 1.0 에서 고정된 코드라 매뉴얼 버전이 올라가도 바뀌지 않는다.

## 6. 개인정보 안내 (이용자가 알아 둘 것)

- Idem 은 본인확인 결과로 만든 **가명 식별자**로 이용자를 구분한다. 서비스에는 그 서비스용 식별자와 서비스가 허용받은 속성(이름 등)만 전달되고, 주민등록번호·연계정보(CI) 원문은 서비스에 가지 않는다.
- 어떤 서비스에 언제 로그인했는지는 운영기관의 감사 기록에 남는다(이용자 보호·분쟁 대응 목적). 열람·정정·탈퇴는 운영기관의 개인정보 처리방침 절차를 따른다.
- 탈퇴(이용 중지) 처리가 되면 모든 서비스에 상태 변경이 전파되고, 그 뒤 Idem 으로 로그인할 수 없다.

## 7. 자주 묻는 것

- **비밀번호를 잊었어요.** Idem 에는 비밀번호가 없다. 로그인은 본인확인(또는 기관 지정 인증)으로 한다. 서비스 자체 계정의 비밀번호는 서비스에서 찾는다.
- **다른 기기에서도 로그인돼 있나요?** 로그인 상태는 브라우저마다 따로다. 각 기기에서 로그아웃하거나 브라우저를 닫는다.
- **로그인했는데 서비스가 "회원이 아닙니다" 라고 해요.** 서비스의 기존 계정과 아직 연결되지 않았다(§3). 서비스의 가입·연결 화면 안내를 따른다.
- **화면에 오류 코드가 떴어요.** §5 표를 보고, 서비스 담당자에게 코드와 추적 ID 를 전달한다.

## 8. 검증한 것 / 못 한 것

- §2.2·§2.3·§5 의 화면과 문구는 저장소 코드(`idem-hub` 코어 로그인 프런트)와 설치본 스모크·통합 테스트에서 확인했다(시험 항목 D-16·D-18).
- §2.1 의 표준 로그인 화면은 Keycloak 화면이다 — 인증 방법 목록·디자인은 설치본과 운영기관 설정에 따라 다르다. 실제 화면 캡처는 GS 시험 환경에서 넣는다(G2).
- 서비스 쪽 화면(가입·연결, 로그아웃 버튼, 오류 표시)은 기관이 만든다 — 이 문서의 서술은 참조 구현(`idem-tenant-sample`) 기준이다.
